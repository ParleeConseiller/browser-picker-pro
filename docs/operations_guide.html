Browser Picker Pro — Operations & Maintenance Guide

Version 2.0.0 · 2026-11-25 · Author: Jose-Jorge HERNANDEZ · Parlee Conseiller, Inc.

1. System description

Browser Picker Pro intercepts web links on Windows and lets the user choose which browser (and profile) opens them, with rules that route known sites automatically. Version 2.0 is built from two executables in the same folder:

ComponentWhat it does
BrowserPickerProLauncher.exe (~2 MB, native)Registered as the link handler. Forwards each link to the running app over a per-user named pipe and exits within milliseconds. Starts the main app if it isn't running.
BrowserPickerPro.exe (~147 MB, self-contained .NET 10 WPF)Runs resident in the notification area (tray). Keeps the picker window and its video background warm, shows the picker (~50–80 ms after the click), launches the chosen browser, then hides back to the tray. Also hosts the Settings dashboard.

2. Prerequisites

  • Windows 10 21H2 or Windows 11, x64. No administrator rights (everything is per-user, HKCU).
  • No .NET runtime needed on the machine (self-contained).
  • To build: .NET SDK 10.0.300 (global.json) and Visual Studio with the Desktop development with C++ workload (the launcher is compiled with NativeAOT).

3. Start, stop and verify status

Start

BrowserPickerPro.exe --tray      # silent start in the tray (what "Start with Windows" uses)
BrowserPickerPro.exe             # start (if needed) and open Settings

Clicking any link also starts it automatically if it isn't running (first open is then ~1.5 s instead of ~0.05 s).

Stop

Right-click the tray icon → Exit. To stop it from a script, stop the exact process by its id — never every process with that name:

Get-Process BrowserPickerPro | Where-Object Path -eq 'C:\path\to\BrowserPickerPro.exe' |
    ForEach-Object { Stop-Process -Id $_.Id }

Verify

  • The tray icon tooltip reads “Browser Picker Pro — ready”.
  • The log contains Picker pre-warmed and resident after start.
  • The link handler points at the launcher: 
    (Get-ItemProperty 'HKCU:\SOFTWARE\Classes\BrowserPickerProHTML\shell\open\command').'(default)'
  • Latency check (from a source checkout): .\scripts\measure-picker-latency.ps1 -Exe <folder>\BrowserPickerProLauncher.exe -Runs 10

4. Log files and monitoring

WhatWhere
Application log (daily, 7 kept, 10 MB/file max)%LOCALAPPDATA%\BrowserPickerPro\Logs\browserPickerPro-YYYYMMDD.log
Crash details (.NET runtime)Windows Event Log → Application, event id 1026

Useful log lines:

  • Picker first frame N ms after link click — end-to-end latency for each link.
  • Reveal timing: launcher→host … settings+rules … prepare … show … (Debug) — where the time goes.
  • Rule matched: … — a rule routed the link without showing the picker.
  • Repeated UI exceptions — exiting instead of looping — the app stopped itself after an error burst; the next link restarts it.
Get-Content "$env:LOCALAPPDATA\BrowserPickerPro\Logs\browserPickerPro-$(Get-Date -f yyyyMMdd).log" -Tail 30 -Wait

5. Configuration parameters

Stored in %APPDATA%\BrowserPickerPro\: settings.json, browsers.json, rules file. Edit through Settings; the resident app re-reads settings.json on every link.

SettingDefaultEffect
KeepRunningInTraytrueResident tray mode. false = v1 behaviour (one process per link). Applies on next start.
StartWithWindowstrueWrites HKCU\…\CurrentVersion\Run\BrowserPickerPro = "…\BrowserPickerPro.exe" --tray.
PickerOpenAnimationCircleRevealNone, CircleReveal, ZoomBlur, SpringRise, PowerOn, Random.
EnableAnimationstrueOff = no opening/closing animation (also off when Windows “Animation effects” is off).
PickerWindowStyle / PickerCardLayoutModal / WrapGridFloating or fullscreen; wrapping grid or single row.
PickerBackgroundMode / PickerBackgroundImagePathDarkGradient / –Custom image or video (mp4, webm, wmv, mov, mkv, avi, gif); videos loop muted.
PickerDarkTintOpacity, PickerCardSize0.55, 190Readability tint over the background; card size in px.

6. Common troubleshooting

SymptomCauseFix
Picker takes over a secondApp wasn't running (cold start).Enable Start with Windows, or start --tray once.
Picker opens behind other windowsLinks aren't going through the launcher.Keep both exes together; restart the tray app (it refreshes an existing registration).
Links open in Edge, picker never showsNot the Windows default browser.Settings → Windows Setup → Register, then pick Browser Picker Pro in Windows Default Apps.
Rebuild fails “file in use”Resident instance runs from the publish folder.scripts\build.ps1 -Publish stops exactly those PIDs.
Launcher build: 'vswhere.exe' is not recognizedVS Installer folder not on PATH.Use scripts\build.ps1, which adds it.
Background video missingFile moved, or codec not installed.Re-pick it in Settings → Appearance; prefer H.264 MP4.

Uninstalling: Exit from the tray, unregister in Settings → Windows Setup, turn off Start with Windows, then delete the folder.
