BrowserPickerProLauncher.exe — Operations Guide

Module of Browser Picker Pro 2.0.0 · Author: Jose-Jorge HERNANDEZ · Parlee Conseiller, Inc.

System description

A ~2 MB native program that Windows runs for every link. It hands the link to the resident Browser Picker Pro tray app over a per-user named pipe and exits within milliseconds; if the tray app isn't running, it starts BrowserPickerPro.exe with the link.

Prerequisites

  • Must sit in the same folder as BrowserPickerPro.exe.
  • Windows 10/11 x64. No runtime, no admin rights.

Start, stop, verify

It is never started by hand and never stays running — each run lasts a few milliseconds. Verify that Windows uses it:

(Get-ItemProperty 'HKCU:\SOFTWARE\Classes\BrowserPickerProHTML\shell\open\command').'(default)'
# expected: "…\BrowserPickerProLauncher.exe" "%1"

Manual test: BrowserPickerProLauncher.exe https://example.com → the picker appears.

Logs and monitoring

The launcher writes no log of its own (to stay fast). Its effect is logged by the tray app in %LOCALAPPDATA%\BrowserPickerPro\Logs\: Picker first frame N ms after link click uses the launcher's start time.

Exit codeMeaning
0Link handed to the tray app, or the app was started.
2BrowserPickerPro.exe not found next to the launcher.
3Starting BrowserPickerPro.exe failed.

Configuration parameters

None. Names are derived from the Windows user and session: mutex Local\BrowserPickerPro.Resident.<user>, pipe BrowserPickerPro.Picker.<user>.<session> (current-user only). Hand-off timeout: 3 s, then cold start.
