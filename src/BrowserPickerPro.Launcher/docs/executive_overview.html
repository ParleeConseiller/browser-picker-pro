The Browser Picker Pro launcher

Executive overview · Module of version 2.0 · Author: Jose-Jorge HERNANDEZ · Parlee Conseiller, Inc.

What problem it solves

The main Browser Picker Pro program is large. Starting it fresh for every link made people wait about a second and a half each time. The launcher is a tiny messenger that removes that wait.

How it works

You click a linkWindows calls the launcher
➜
Launcher passes it onto the app already waiting in the tray
➜
Picker appearsin well under a tenth of a second

Key benefits

  • The picker feels instant — about twenty times faster than before.
  • Uses no memory between clicks: it runs only for a few thousandths of a second.
  • If the main app isn't running yet, the launcher simply starts it — nothing breaks.
